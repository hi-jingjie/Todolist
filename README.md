# PlanProof · 微信待办小程序

面向大学生的证据驱动 AI 任务规划工具。项目从本地优先的待办工具演进而来：V1 提供可靠的任务管理，V2（PlanProof）把通知或作业要求转成需要用户逐条确认的任务草稿，并用实际耗时持续校准每日计划。

## V1 与 V2

- **V1.0.0**：本地待办、分类、筛选、重复任务、专注计时、统计和归档。稳定版本见 [Release](https://github.com/hi-jingjie/Todolist/releases/tag/v1.0.0)。
- **V2 / PlanProof**：文本通知 AI 导入、证据校验、人工确认、CloudBase 密钥边界、确定性每日计划与耗时反馈。本阶段只支持文本，不包含 OCR、图片或 PDF 解析。

## 为什么不是普通的 AI 待办

- 模型只返回任务草稿，不直接写入用户数据。
- 每条 `evidenceQuote` 必须是用户原文的连续片段；无法逐字对应原文的草稿会被拦截。
- 原文没有明确的截止日期或信息不足时，使用 `null` 和不确定项显示，而不是编造。
- 每日计划由确定性规则生成：逾期、截止日、优先级、创建顺序；模型不参与排程决策。
- 实际耗时会校正未来预估，校准系数限制在 50% 到 200%。

## 主要功能

- 待办新增、编辑、搜索、分类和自定义分类
- 状态、优先级筛选以及日期、优先级排序
- 截止日期状态、逾期提示、任务置顶和批量操作
- 任务备注以及每天、每周、每月重复任务
- 绑定待办的专注倒计时与专注时长记录
- 完成归档、恢复和删除
- 最近 7 天完成趋势、分类完成占比和数据概览

## 本地运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，项目目录选择本仓库根目录。
3. 使用自己的小程序 AppID，或选择不使用 AppID 的本地测试方式。
4. 点击“编译”即可预览。

## 开通 V2 云开发

1. 在微信开发者工具点击“云开发”，开通一个环境；项目已在 `project.config.json` 配置 `cloudfunctionRoot: "cloudfunctions/"`。
2. 右键 `cloudfunctions/task-extractor`，选择“上传并部署：云端安装依赖”。
3. 在云函数环境变量中配置三个值：
   - `MODEL_API_URL`：OpenAI 兼容模型服务的完整接口地址。
   - `MODEL_API_KEY`：该服务的访问密钥。
   - `MODEL_NAME`：要调用的模型名称。
4. 编译小程序，使用首页的“AI 导入任务”和“今日计划”入口体验 V2。

密钥只存在云函数环境变量中，绝不提交到 Git；`.dev.vars*` 已被忽略。

V2 流程：粘贴通知 → 云函数生成候选任务 → 客户端验证原文依据 → 用户逐条确认 → 本地保存 → 确定性每日排程 → 录入实际耗时。

## 数据说明

待办、分类和专注记录使用 `wx.setStorageSync` 保存在当前微信用户与设备的小程序本地空间。删除小程序数据、清理微信缓存或更换设备后，数据不会自动同步恢复。

## 自动测试

测试使用 Node.js 内置断言，可在项目根目录逐个运行：

```powershell
Get-ChildItem tests\*.test.js |
  Sort-Object Name |
  ForEach-Object { node $_.FullName }
```

`evals/notification-fixtures.js` 提供匿名样例，覆盖明确截止日、未知截止日、多任务通知和虚构证据拒绝；`tests/plan-proof-workflow.test.js` 跑通“校验 → 确认保存 → 每日排程”的完整本地流程。

## 开发者工具人工检查清单

- [ ] 空白文本不能发起提取，超过 5000 字会被拦截。
- [ ] 模型或网络失败时，原始文本仍保留在输入框。
- [ ] 原文依据不匹配的草稿没有“确认并加入待办”按钮。
- [ ] 确认一张草稿只新增一条任务，不影响其他候选卡片。
- [ ] 切换 60/120/180 分钟会重新计算每日计划；未排入任务仍可见。
- [ ] 非正数实际耗时会被拒绝；保存有效分钟数后重开页面仍能看到。

## 项目结构

- `pages/index`：待办首页、筛选和批量操作
- `pages/todo-edit`：新增与编辑待办
- `pages/focus`：专注倒计时
- `pages/stats`：任务与专注统计
- `pages/archive`：已完成任务归档
- `pages/ingest`：AI 文本导入与逐条确认
- `pages/plan`：确定性每日计划和实际耗时反馈
- `cloudfunctions/task-extractor`：CloudBase 模型调用边界，不向客户端暴露密钥
- `utils/plan-proof`：草稿验证、映射、排程、校准和页面状态
- `evals`：匿名任务提取评测样例
- `utils`：任务、日期、分类、筛选和统计逻辑
- `tests`：数据逻辑自动测试
