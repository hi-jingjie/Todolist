# Todolist 微信小程序

一个使用微信小程序原生框架开发的待办与专注工具。第一版以本地使用为主，任务数据保存在微信小程序本地存储中，不依赖服务器。

## 主要功能

- 待办新增、编辑、搜索、分类和自定义分类
- 状态、优先级筛选以及日期、优先级排序
- 截止日期状态、逾期提示、任务置顶和批量操作
- 任务备注以及每天、每周、每月重复任务
- 绑定待办的专注倒计时与专注时长记录
- 完成归档、恢复和删除
- 最近 7 天完成趋势、分类完成占比和数据概览

## 本地运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，项目目录选择本仓库根目录。
3. 使用自己的小程序 AppID，或选择不使用 AppID 的本地测试方式。
4. 点击“编译”即可预览。

## 数据说明

待办、分类和专注记录使用 `wx.setStorageSync` 保存在当前微信用户与设备的小程序本地空间。删除小程序数据、清理微信缓存或更换设备后，数据不会自动同步恢复。

## 自动测试

测试使用 Node.js 内置断言，可在项目根目录逐个运行：

```powershell
Get-ChildItem tests\*.test.js |
  Sort-Object Name |
  ForEach-Object { node $_.FullName }
```

## 项目结构

- `pages/index`：待办首页、筛选和批量操作
- `pages/todo-edit`：新增与编辑待办
- `pages/focus`：专注倒计时
- `pages/stats`：任务与专注统计
- `pages/archive`：已完成任务归档
- `utils`：任务、日期、分类、筛选和统计逻辑
- `tests`：数据逻辑自动测试

## 隐私与发布

仓库不应包含 AppSecret、上传密钥或微信开发者工具个人配置。`project.private.config.json` 已加入忽略列表。正式发布前，请按微信公众平台要求补充隐私保护指引和必要的服务类目。
